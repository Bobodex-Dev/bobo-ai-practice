# Bobo AI Practice

The practice repository for the Bobo University course "Code With an AI Agent: Start Here".

It is being built. When it is ready, this will be a small Study Board app with planted bugs, each paired with a test, and you will fix them by directing an AI coding agent, one habit per chapter.

Copy it with:

    gh repo create bobo-ai-practice --template Bobodex-Dev/bobo-ai-practice --private --clone --include-all-branches
